# Dota 2 Custom Grid Creator 🎮

Программа на **Python** с графическим интерфейсом (CustomTkinter) для создания
**кастомных сеток героев Dota 2** (Custom Hero Grid — как в режиме Turbo/Brawl
или в кастомных играх). Главная «фишка» — **автоматическая конвертация
рисунков в символьную сетку** и **автоматический поиск папки сеток героев**.

```
[anti_mage]
grid="aabbc|addee|adff.|.ggg.|....."
```

---

## ✨ Возможности

- 🔍 **Автоматический поиск папки сеток героев Dota 2** (Steam, Windows/Linux) —
  при запуске программа сама находит нужную папку и загружает все сетки.
- 🖼 **Добавление рисунков с автоматической конвертацией в символы**:
  картинка (PNG/JPG/BMP/GIF/WEBP/TIFF) масштабируется до размера сетки,
  порогуется по яркости, а связные области превращаются в блоки-символы
  `a`, `b`, `c`, … Можно настроить порог, инверсию, способ вписывания
  (contain / cover / stretch) и минимальный размер области (уборка шума).
- 🎨 **Визуальный редактор**: рисуйте клетки мышью (ЛКМ — добавить блок,
  ПКМ — стереть), каждый блок подсвечен своим цветом и подписан символом.
- 📋 Список всех сеток с поиском по имени героя, создание/переименование/
  удаление, изменение размера сетки (до 12×12).
- 💾 Сохранение прямо в папку игры в формате `[hero_name] grid="..."`,
  импорт `.txt/.ini` файлов и экспорт всех сеток в один файл.
- ⚠ Защита от потери несохранённых изменений, статусная строка, тёмная тема.

## 📀 Требования

- Python **3.10+**
- Зависимости:

```bash
pip install -r requirements.txt
# или вручную:
pip install customtkinter pillow
```

> В Linux также может понадобиться системный пакет Tk:
> `sudo apt install python3-tk`

## 🚀 Запуск

```bash
cd dota_grid_creator
python main.py
```

После запуска нажмите **«🔍 Найти автоматически»** (поиск выполняется сам при
старте). Если Dota 2 установлена в нестандартное место — используйте
**«📂 Выбрать вручную…»**.

### Типичные пути, которые программа ищет автоматически

| ОС      | Путь |
|---------|------|
| Windows | `C:\Program Files (x86)\Steam\steamapps\common\Dota 2 beta\game\dota_addons\hero_demo\maps\grids` |
| Windows | `...\Steam\steamapps\common\Dota 2\gamesettings\custom_grids` |
| Linux   | `~/.steam/steam/steamapps/common/Dota 2 beta/game/dota_addons/hero_demo/maps/grids` |

Если ни один известный путь не подошёл, программа выполнит ограниченный
эвристический обход дисков/домашней папки в поисках каталога с файлами вида
`grid="..."`.

## 🧭 Как пользоваться

1. **Найдите папку сеток** — кнопка «🔍 Найти автоматически» (или выберите вручную).
2. **Выберите героя** из списка слева (или создайте нового кнопкой «＋ Новая»).
3. Рисуйте сетку мышью прямо на холсте: ЛКМ — поставить клетку блока,
   ПКМ — стереть. Размер сетки меняется полями «Размер» (по умолчанию 5×5).
4. **Добавьте рисунок**: «🖼 Выбрать картинку…» → настройте порог яркости /
   инверсию / вписывание → «⚡ Конвертировать в сетку» (заменит текущую сетку)
   или «Добавить как новый герой…».
5. Нажмите **«💾 Сохранить»** — файл `<hero_name>.txt` появится в папке сеток.
6. Перезапустите Dota 2 / кастомную игру, чтобы сетка применилась.

### Пример конвертации

Рисунок-буква «G» на белом фоне после конвертации в сетку 5×5:

```
.....        .....
.aaa.   →    |.aaa.|.a...|.aaa.|.....
.a...
.aaa.
.....
```

---

## 📄 Формат файла сетки

Каждый герой описывается блоком:

```ini
[npc_dota_hero_axe]
grid="aa.bb|aaccc|add.d|..dd.|ee.ee"
```

- `|` — разделитель строк;
- `.` — пустая клетка;
- одинаковые буквы/цифры — одна связная область (блок) героя.

## ❓ Частые вопросы

**Не нашёл папку автоматически.** Нажмите «📂 Выбрать вручную…» и укажите папку,
где лежат `.txt`-файлы сеток (см. таблицу путей выше).

**Рисунок сконвертировался «не так».** Попробуйте: изменить порог яркости
(ползунок), включить «Инвертировать» (для светлых фигур на тёмном фоне),
сменить режим вписывания (`cover` заполняет всю сетку, `stretch` растягивает),
увеличить «Мин. размер области», чтобы убрать одиночные шумовые клетки.

**Имя героя.** Используйте внутриигровое имя без префикса
`npc_dota_hero_`: например `anti_mage`, `faceless_void`.

## ⚠ Дисклеймер

Программа не связана с Valve / Dota 2. Она редактирует только текстовые файлы
кастомных сеток и предназначена для пользовательских лобби/кастом-игр,
поддерживающих формат Custom Hero Grid.
